# Archived experiment scripts

These files preserve earlier iterations of the thesis experiments. They are kept for provenance and are not the recommended entry points:

- `mallorn.py` - initial single-model experiment
- `mallorn2.py` - extended evaluation and visualization
- `mallorn3.py` - revised high-resolution figures
- `02_fix_fractional_pivot.py` - one-off repair utility for an earlier feature-table format

Use the `run_*.py` scripts in `../scripts/` for the final thesis workflow. Archived files may use earlier feature definitions, plots or assumptions and are not covered by the current reproduction instructions.
